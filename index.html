Featured work

NFSv4 ACL Cache Invalidation

I needed to understand why an NFSv4 client kept enforcing a stale ACL after a permission change on the server, with no clean way to force it to re-fetch. So I wrote a small Linux kernel module that flushes the cached ACL for a given path on demand, and a companion bpftrace script that hooks the client's GET_FACL call to trace every ACL fetch live, instead of guessing from behaviour.

  • → NFSv4.1 / NFSv4.2
  • → bpftrace
